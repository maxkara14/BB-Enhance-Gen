# Enhance Gen: инструкции и пользовательские кнопки

Ветка: `enhance-test`. Направление согласовано 2026-09-14.

## Объём нового этапа

- Редактор основной инструкции Enhance / Improve со сбросом к стандартной.
- Пользовательские кнопки обработки непустого черновика: название, текстовая иконка, инструкция, включение, изменение и удаление.
- Штатные стили, общее подключение, потоковый вывод, отмена, повтор и восстановление оригинала.
- Контекст добавляется автоматически. Язык, лицо повествования и сохранение реплик из настроек имеют приоритет; множитель длины применяется только к Enhance.
- Настройки общие для расширения. Повтор сохраняет инструкцию исходного запроса; текущий чат и ручные правки защищены.
- Интерфейс RU/EN. Полные шаблоны, редакторы Director/FT/TS/d20, отдельные подключения для кнопок и импорт/экспорт не входят в этот этап.
- Пользователь одобрил версию 1.5.0, коммит и push в `enhance-test`. Перенос в `main` — только после отдельного подтверждения по итогам проверки.

## Закрытие диагностики Fast Travel

Старые пункты «ожидаются данные» устарели. Пользователь предоставил ответ
HTTP 400 с `prompt_blocked / PROHIBITED_CONTENT`: конкретный запрос был
заблокирован провайдером. Обработка завершена понятным сообщением
«Провайдер заблокировал запрос» без автоматического fallback.

Почему этот провайдер принимает Time Skip или запрос профиля, но блокирует
Fast Travel через Custom API, не установлено. Это известное внешнее ограничение,
а не невыполненная задача обещать обход блокировки. Изменения парсера и режима
потока не считаются устранением фильтрации.
