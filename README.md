# 🎬 BB Enhance Generation

Компактная панель инструментов для **SillyTavern** — помогает быстро редактировать черновик, расширять сцены, бросать кубики и управлять темпом ролевого отыгрыша. Всё в одной маленькой кнопке `E` рядом с меню волшебной палочки.

В версии **1.4.0** меню, настройки и окна используют единое оформление:
полупрозрачный чёрный фон, светлый текст и приглушённые красные акценты.
Наведение и нажатие меняют цвет кнопок без сдвигов. Окна закрываются крестиком или Escape.
В Fast Travel / Time Skip ручные поля находятся под «Изменить или задать своё»;
выбор карточки заполняет их и подсвечивает выбранный вариант.

В **1.4.1** отказ Fast Travel / Time Skip сопровождается объяснением.
«Проверить ещё раз» повторно запрашивает варианты по текущей сцене — модель может снова отказать.
«Задать свой переход» раскрывает три обязательных поля и подтверждение авторского решения.
Галочка разрешает выполнить заполненный вручную переход; новые варианты она не генерирует.

В **1.4.2** исправлены JSON-примеры в запросах Fast Travel / Time Skip:
теперь они содержат все три обязательных варианта и отдельный пример отказа.
Ранее модель могла повторить пример с одним вариантом, который проверка формата отвергала.

В **1.4.3** ответы через профиль подключения различают пустой результат и результат,
содержащий только рассуждения без финального текста. Во втором случае сообщение предлагает
проверить лимит токенов операции и настройки рассуждений профиля. Рассуждения не используются
как итоговый ответ. Это диагностика, а не автоматическое исправление поведения модели.

В **1.4.4** Custom API принимает текстовые блоки в `message.content` и текст в
`choices[0].text`, включая потоковые ответы. Ранее эти формы ответа могли приводить
к ошибкам пустого текста или потока. Распознавание ответа только с рассуждениями
теперь действует и для Custom API; рассуждения не подставляются вместо результата.

## ✨ Что умеет

### 🔸 Enhance
Берёт короткий черновик в поле ввода и превращает его в насыщенный литературный фрагмент: добавляет детали окружения, ощущения, внутренний голос персонажа. Сюжет вперёд не двигает — расширяет то, что уже задумано.

В версии **1.2.0** результат открывается в отдельном окне рядом с оригиналом.
Его можно отредактировать, повторить генерацию или применить. До применения
поле ввода не меняется, включая стриминг. Степень расширения: ×1.5, ×2 или ×3.

### 🔸 Improve
Аккуратно полирует уже написанный текст: подтягивает ритм, выправляет неуклюжие места, убирает повторы. Длину сохраняет, новых событий не вводит.

Для текстовой генерации доступны сохранение реплик дословно, выбор лица
повествования и языка результата. Эти параметры передаются модели как
инструкции; точное соблюдение длины зависит от модели. После применения можно
нажать **«Вернуть оригинал»**. Возврат доступен для последнего применения в
текущем чате, пока результат не изменён вручную и чат не переключён.

### 🔸 Event Director 🎬
Добавляет в сцену сюжетный поворот заданного настроения:
- 💥 **Disaster** — драматическое нарушение, опасность, плохое событие.
- 🎁 **Blessing** — удача, тёплый момент, приятное открытие.
- ❤️ **Tension** — эмоциональное или романтическое напряжение.
- 🃏 **Absurd** — лёгкая нелепица, неожиданный поворот без вреда.
- 💀 **Tragedy** — тяжёлая, неотвратимая потеря.
- ✏️ **Своё (Custom)** — свободное текстовое направление. Пишете что угодно своими словами на любом языке: «Подготовиться к приезду людей из Широгане», «пусть начнётся дождь», «introduce a mysterious stranger» — и расширение направит сюжет точно по вашему запросу.

Для каждого варианта можно выбрать, куда направить событие:
- **Мне** — расширение само пишет следующий фрагмент сцены от лица персонажа игрока.
- **Боту** — подкладывает скрытую подсказку, по которой следующий ответ напишет уже основная модель SillyTavern.

В настройках задаются интенсивность события (намёк, заметное событие,
перелом сцены) и тип Tension: романтический, конфликтный или тревожный.
Они работают для обоих направлений. «Мне» вставляет готовый текст прямо в поле ввода чата,
без отдельного предпросмотра. При включённом потоковом выводе профиля / Custom API текст
появляется в поле чата по мере получения. При отмене или ошибке возвращается исходный
черновик; собственные правки, сделанные во время запроса, не затираются.
В «Своё» кнопки «Мне» и «Боту» находятся сразу под указанием, без шага «Далее».
Указание после «Мне» сохраняется для повторного запуска до смены чата или перезагрузки.
«Вернуть оригинал» возвращает предыдущий черновик, если результат ещё не отредактирован.

### 🔸 Action Roll 🎲
Анализирует последнее действие игрока, формулирует короткий драматический вопрос («удастся ли задуманное?») и бросает d20 на анимированном 3D-кубике. По итогу подкладывает в чат скрытую подсказку для бота — отыграть успех или провал. Поддерживаются классические сложности: Easy (DC 8), Normal (DC 12), Hard (DC 16), Epic (DC 20) и Random (DC 10–16).

Вопрос можно вводить вручную — тогда служебного запроса модели нет.
Вместо шестигранного куба отображается вращающийся двадцатигранник с 20 треугольными
гранями. Число на передней грани совпадает с рассчитанным результатом; анимация
не влияет на бросок и останавливается при закрытии окна.
Анимацию можно пропустить кнопкой или отключить в настройках; системная
настройка уменьшения движения также учитывается. После результата выберите
«Продолжить» или отмените действие. Последние 10 подтверждённых бросков хранятся
отдельно для каждого чата в хранилище аккаунта SillyTavern. Окно показывает только
текущий чат и закрывается крестиком или Escape. Кнопка очистки появляется при
наличии записей. Переключатели старой общей истории убраны; архив в локальном
хранилище не удаляется и не переносится в другие чаты.

### 🔸 Fast Travel ⏩
Проверяет, можно ли логично покинуть текущую сцену. Если да — предлагает три осмысленных направления (или случайное событие), исходя из контекста чата. Выбор отправляется боту как короткая режиссёрская инструкция.

Выбор заполняет редактируемые поля места, времени и направления сцены.
Можно написать собственный вариант или обновить предложения. Если модель
советует не уходить, можно явно подтвердить авторское решение и задать переход.

### 🔸 Time Skip 📍
Анализирует, готова ли сцена к промотке времени, и предлагает кинематографичные варианты «через сколько и куда». Удобно для перехода между актами без ручного описывания дороги.

Поддерживает тот же редактор, обновление и авторское решение, что Fast Travel.
Намерение из черновика учитывается при анализе. Неверный JSON не считается
разрешением на переход: расширение показывает ошибку, ничего не отправляя.

## ⚙️ Настройки

### Кнопки панели
Каждую из шести функций можно индивидуально скрыть или показать в тулбаре. Иконка `E` остаётся переключателем — сворачивает и разворачивает всю панель.

В **1.2.1** настройки снова используют стандартный блок SillyTavern и доступны
для перемещения в Extension-Sorter. Внутри — компактные сворачиваемые секции;
смена языка не выносит панель из выбранной папки. Меню Event Director открывается
сбоку от панели, без сдвига соседних кнопок. У края экрана выбирается доступная
сторона; на узком экране окно удерживается в пределах видимой области.

### Источник генерации и профили подключения

В секции **«Модель для генерации» → «Источник»** доступны:

- **Текущее подключение SillyTavern** — основная модель с контекстом, собранным Enhance Gen;
  ответ извлекается до обработки regex для сообщений бота.
- **Профиль подключения SillyTavern** — сохранённый текстовый профиль Connection
  Manager. Выберите профиль из списка; после изменения профилей нажмите
  «Обновить профили». Используются модель, подключение, пресет и instruct
  выбранного профиля, без переключения активного подключения чата.
- **Custom API** — отдельный OpenAI-совместимый URL, ключ и модель.

Источник применяется к Enhance, Improve, Director «Мне», анализу FT/TS и
формулировке вопроса кубика. Ответ Director «Боту» и отыгрыш подсказок по-прежнему
генерирует основное подключение чата.

Запрос профиля поддерживает отмену, тайм-аут, лимиты длины и потоковый вывод.
В секции «Модель для генерации» включите «Потоковый вывод (профили / Custom API)».
Без этой настройки результат вставляется целиком. Недоступный или удалённый профиль показывает ошибку и не
заменяется основной моделью автоматически. Ключи профилей не копируются в
настройки расширения. Для профилей нужен включённый Connection Manager с
поддержкой `ConnectionManagerRequestService` (Chat Completion / Text Completion).

### Чистая генерация и «Своё → Мне» (1.3.0)

«Своё → Мне» просит написать ход за вашего персонажа: описать указанные действия,
которые ещё не произошли, вместо продолжения после них.

Для служебных запросов основной модели используется отдельная сборка: персонаж,
персона игрока, сценарий, заметка автора, summary и последние сообщения в пределах
бюджета. Полный prompt чата, World Info и инструкции пресета автоматически не добавляются.
Параметры модели берутся из текущего подключения. Ответы «Боту» остаются обычной генерацией чата.

Из HTML-контекста удаляются скрипты, стили, встроенные страницы и явно скрытые блоки;
абзацы и видимый текст сохраняются. Неизвестные маркеры и скобки больше не вырезаются
наугад. Явный технический блок в результате блокирует применение и предлагает повторить
запрос. Director «Мне» показывает поток в поле чата и восстанавливает черновик при ошибке;
Enhance и Improve используют «Применить» в предпросмотре.

Это не гарантия очистки любого формата: видимые панели без явной разметки и неизвестные
служебные маркеры могут остаться. Общие обработчики запросов сторонних расширений
SillyTavern также продолжают работать. Профили используют свой прежний путь Connection Manager.

### Custom API (OpenAI-compatible)
Для быстрых служебных генераций можно подключить **отдельный API** (Groq, любой OpenAI-совместимый прокси и т.п.):
- Своя ссылка, ключ и модель.
- Кнопка «Connect / Refresh» подтягивает список доступных моделей.
- Опциональный **стриминг** профилей / Custom API — текст Enhance/Improve появляется в
  предпросмотре, а Director «Мне» — прямо в поле чата. Основная модель через raw API
  по-прежнему возвращает готовый ответ целиком.
- **Тайм-аут** — от 15 до 600 секунд, по умолчанию 120. «Отмена» останавливает текущую операцию.
- **Переход на основную модель при ошибке** можно отключить. При включённой настройке первое переключение сопровождается уведомлением. После отмены, частичного ответа, ограничения длины или фильтрации незаметной повторной генерации не происходит.
- Если выбран текущий источник SillyTavern или в Custom API не заполнены URL/модель, используется основная модель SillyTavern. Старый переключатель Custom API при обновлении сохраняется как соответствующий выбор источника.
- Имя модели можно вводить вручную, даже если провайдер не поддерживает список `/models`.

### Лимиты длины ответа (max_tokens)
Четыре независимых поля под каждый тип задачи — чтобы Режиссёр мог писать развёрнутые сцены, а Action Roll не тратил токены зря:

| Тип | Что это | Дефолт |
|---|---|---|
| 🎬 **Режиссёр → «Мне»** | Полноценный художественный сегмент | 5000 |
| ✨🔮 **Enhance / Improve** | Полировка короткого черновика | 1500 |
| ⏩📍 **Контекст-анализ (FT / TS)** | Чтение чата → компактный JSON | 2000 |
| 🎲 **Микро (вопрос для броска)** | Одна короткая фраза | 500 |

В каждом поле `0` = не задавать лимит в запросе (`max_tokens` не отправляется).
Ограничения и значения по умолчанию провайдера при этом остаются. Остальные
значения зажимаются в диапазон 64–8000. Для основной модели лимит передаётся
через `responseLength` SillyTavern.

### Контекст

Глубина: 1–40 последних несистемных сообщений, по умолчанию 8. Бюджет:
4000–60000 символов, по умолчанию 16000. Контекст включает персону, описание
текущего персонажа, сценарий, доступные Author's Note и Summary, а также
последние сообщения без собственных режиссёрских вставок. До половины бюджета
отводится описаниям, остаток — последним сообщениям; длинные данные обрезаются.
Сам черновик и инструкции задачи считаются отдельно.

Это бюджет контекста, который собирает расширение для Custom API. Основная
модель вызывается через `generateQuietPrompt` и дополнительно использует
контекст, макросы, World Info и настройки самого SillyTavern. Бюджет расширения
не ограничивает весь итоговый запрос основной модели.

### Action Roll
- **Сложность по умолчанию** — выбранное значение применяется к каждому броску автоматически, попап выбора не показывается.
- **Каждый раз спрашивать сложность** — включите, если перед каждым броском хотите видеть попап выбора. В этом режиме селект сложности по умолчанию блокируется (он всё равно не используется).

### Прочее
- **Предпросмотр подсказки для бота** — показывает скрытый текст, который расширение собирается подкинуть боту (Director / Action Roll / FT / TS), и позволяет отменить отправку.
- **Журнал бросков** — последние 10 бросков текущего чата; очистка затрагивает только его историю. Бросок записывается после «Продолжить», даже если позднее отменить предпросмотр подсказки.
- **Язык интерфейса** — автоматически по браузеру или вручную RU / EN. Язык результата задаётся отдельно. Режиссёрские инструкции остаются английскими, видимые метки локализованы.
- **Индикатор занятости** — активная кнопка инструмента пульсирует; остальные сохраняют
  обычное оформление, повторный запрос защищён общей блокировкой. «Остановить»
  меняется на «Остановка…», пока запрос завершает отмену. Окна закрываются по Escape,
  поддерживают Tab и возврат фокуса.
- **Переключение чата** отменяет операцию и закрывает устаревшие окна. Если черновик изменился во время запроса, Director «Мне» сохраняет ваши правки и сообщает об отменённой вставке. В Enhance/Improve результат остаётся доступен в предпросмотре.

## 🔒 Безопасность

API-ключ Custom API сохраняется в настройках SillyTavern в открытом виде (так устроена платформа). Не используйте этот механизм на чужих устройствах и не делитесь дампами настроек.

Расширение не пишет полный промпт, ключ или текст переписки в собственные логи.
Модельный текст в окнах и подсказках экранируется. Предпросмотр художественного
текста использует текстовое поле, а не исполнение HTML. Custom API вызывается
из браузера и должен разрешать такие запросы (CORS).

## 📦 Установка

1. Откройте SillyTavern.
2. Перейдите в `Расширения → Установить расширение`.
3. Вставьте ссылку на репозиторий:
   ```
   https://github.com/maxkara14/BB-Enhance-Gen
   ```
4. Перезагрузите страницу.
5. Панель появится рядом с меню волшебной палочки — кнопка `E`. Нажмите её, чтобы развернуть тулбар.
